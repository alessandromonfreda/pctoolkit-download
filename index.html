Compulandia PC Toolkit

App portatile per assistenza tecnica: diagnostica hardware, pulizia, backup dati e gestione driver in un'unica interfaccia. Nessuna installazione richiesta.

Versione per Windows 10/11

Per un altro PC: Windows 10/11 · Windows 7/8.1 (zip)

  • Windows 10/11 a 64 bit; per Windows 7/8.1 una cartella zip: estrarla e avviare CompulandiaPCToolkit.exe (installa .NET Framework 4.8 da solo se manca)
  • Eseguibile singolo, portatile — nessuna installazione
  • Diagnostica hardware, dischi, processi, avvio, servizi, eventi
  • Backup dati multi-profilo con supporto credenziali
Nota: aprendo il file scaricato, Windows mostra un avviso di sicurezza perché l'eseguibile non è ancora firmato digitalmente (normale, non è un'installazione). Basta cliccare "Esegui" — se invece compare lo schermo blu "Windows ha protetto il PC", cliccare "Ulteriori informazioni" → "Esegui comunque".
